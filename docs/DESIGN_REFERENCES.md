# Design research and references

Researched on 12 October 2026. These references informed design principles and information architecture; the page uses original copy, CSS compositions, and inline SVG artwork rather than copying layouts or assets.

## Data-science case study structure

**Colorlib — [24 Best Data Science Portfolio Examples 2026](https://colorlib.com/wp/data-science-portfolio-examples/)**

Useful principle: introduce each project with its question, approach, and an evidence-backed result. The article also emphasizes choosing metrics that accurately describe the work, and linking a repository or live demo when one exists. This portfolio uses concise case notes and only reports the 90% CNN accuracy stated in the supplied project summary; it does not invent an evaluation protocol.

## Data visualization as the work itself

**Nadieh Bremer / Visual Cinnamon — [Portfolio](https://www.visualcinnamon.com/portfolio/)**

Useful principle: treat visual communication as a first-class technical skill and organize work so viewers can scan and filter different kinds of projects. This influenced the custom signal / chart artwork and the project-category controls.

## Strong navigation and project hierarchy

**Brittany Chiang — [Portfolio](https://brittanychiang.com/)**

Useful principle: keep navigation direct, separate projects from skills and writing/context, and make project titles and technologies easy to scan. The new information architecture separates work, capabilities, experience, education, and contact rather than putting everything into one undifferentiated card wall.

## Typographic restraint and intentional motion

**Astro Themes — [Monochrome Portfolio](https://astro.build/themes/details/monochrome-portfolio/)**

Useful principle: use type, hierarchy, borders, and short transitions to make the interface feel considered without decorative noise. The redesign uses compact monospaced labels, oversized display type, restrained reveals, and reduced-motion support.

## A memorable portfolio identity

**Bruno Simon — [Interactive Portfolio](https://bruno-simon.com/)**

Useful principle: let the visual concept express the builder's strengths. This portfolio takes a lighter-weight route: a custom signal-plot scene and CSS-made project illustrations rather than a full 3D experience that could distract from data-science work or slow down mobile devices.

## How the references were applied

- Use high-contrast dark surfaces with one vivid accent, plus restrained secondary color.
- Lead with one clear statement about the work rather than vague superlatives.
- Give featured projects specific descriptions and expandable context.
- Keep claims and metric provenance explicit.
- Use original, lightweight visuals to demonstrate visual craft.
- Preserve mobile usability, semantic sections, keyboard focus, and reduced-motion behavior.
